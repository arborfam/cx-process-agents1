# Оригінали BPMN-пайплайна власниці (еталон, лише для читання)

**Стан: непозмінені копії.** Збережено 30.09.2026 за дозволом власниці продукту. Файли в `original/` **не редагувати**: вони потрібні як еталон для порівняльних тестів генератора (технічний план, зріз 3a) і як довідник правил відображення нотації. Застосунок і його тести цю папку **не використовують** і не виконують ці скрипти.

Перевірка незмінності: контрольні суми SHA-256 копій збігаються з отриманими файлами (перевірено `cmp` під час збереження). `.gitattributes` (`* -text`) забороняє Git змінювати закінчення рядків, щоб байти лишалися тими самими (важливо для `run_pipeline.sh` на Windows). Якщо файл змінено, рядок нижче перестане збігатися:

```
sha256sum original/*    # порівняти з таблицею
```

## Примітки
- Початкова українська назва файлу з описом рішення втратилась під час завантаження (збережено з підкресленнями).
- Скрипти мають **відомі дефекти** (лапки в назвах, повторні ID, спільні файли `/tmp`, мовчазні пропуски): див. `docs/bpmn-pipeline-assessment.md`. Вони **не виправляються** в оригіналах; виправлена версія логіки буде написана на TypeScript у застосунку (D22).
- Файли містять внутрішні назви (процеси, ролі, корпоративний простір імен). Репозиторій приватний; не публікувати його без окремого рішення власниці.
- Ліцензія стороннього пакета `bpmn-auto-layout`, який використовує `layout_step.mjs`: MIT (перевірено, `docs/technical-plan.md`, розділ 1б). Права на самі скрипти належать власниці.
