# Стартовий пакет для Claude Code

29.09.2026. Це специфікації та початкові інструкції, а не готовий застосунок.

## Як почати

1. Розпакуйте архів на комп’ютері.
2. Додайте ВМІСТ папки cx_starter в корінь окремого приватного GitHub-репозиторію. CLAUDE.md має бути в корені. Збережіть початковий commit.
3. У Claude Code у браузері підключіть цей репозиторій і почніть сесію.
4. Вставте повний текст START_HERE.md як перше завдання.
5. Перегляньте технічний план і відкриті рішення перед початком реалізації.

GitHub-репозиторій — папка проєкту з історією змін. Cloud-сесія Claude Code — середовище розробки. Розміщення готового застосунку і доступ до моделі під час його роботи — окремі рішення.

## Файли

- CLAUDE.md — короткі правила для Claude-розробника.
- docs/prototype-spec.md — повна специфікація і поведінковий контракт, збережена копія версії 0.1.
- prompts/analyst.md — початкова інструкція продуктового агента 1.
- prompts/bpmn.md — початкова інструкція продуктового агента 2.
- docs/hooks-plan.md — план hooks і межі їхнього застосування.
- docs/acceptance.md — критерії приймання першого технічного плану та реалізації.
- START_HERE.md — перше завдання для вставлення в Claude Code.

Інструкції агентів — вихідні тексти для майбутнього застосунку. Вони не встановлюють Claude Code subagents і самі нічого не запускають. JSON-схеми, код і активні hooks будуть додані після визначення технічного способу реалізації. Повний навчальний набір інтерв’ю до архіву не включений: перед тестуванням додати синтетичний CX_ASIS_discovery_inputs_draft.md і явно позначені уточнення. Не підміняти його вигаданими результатами запуску.
