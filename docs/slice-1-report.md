- Застосунок Node.js 22 + TypeScript + SQLite (`src/`, `public/`): кейси, джерела, версії, питання, погодження, стани, журнал.

- Постійна позначка «ДЕМОРЕЖИМ — не AI»; демо-кейс і його питання позначені як задані сценарієм.
- Документи: технічний план (уточнено: розділи 1а і 3а), журнал рішень (D4 уточнено, D18, D19), інструкція docs/demo-guide.md, знімки docs/demo/.

## Що ще не працює або не перевірено
- **Немає справжнього AI:** кнопка «Оновити аналіз (AI)» вимкнена; ключа моделі в середовищі немає. Агент 1 представлений лише підставним клієнтом у тестах (mode=demo).
- **BPMN не будується:** сервер лише перевіряє дозвіл і записує запуск зі станом `not_implemented` (зріз 3). Перевірка відповідності BPMN (розділ 1а) — лише спроєктована.
- Підсумкового документа немає (зріз 4). Файли лише `.txt`/`.md`.
- Ваш запуск на Windows/Mac **не пробувався**; перевірено в Linux-контейнері. Розміщення (D6) не обране, нічого не опубліковано.
- Автентифікація мінімальна (код доступу + cookie, лише 127.0.0.1): прототип однокористувацький.
- Знімки я переглянула не всі (детально: 02, 04, 05, 08, 11); решта створені тим самим сценарієм без помилок.
- `node:sqlite` експериментальний (D5); CI і hooks **не активовано** (команди `npm test` і `npm run typecheck` тепер існують, тож кандидатів із D17 можна активувати за вашою згодою).
- Оцінку якості змісту й читабельності «за хвилину» людиною не проведено: це ваша перевірка за docs/demo-guide.md.
