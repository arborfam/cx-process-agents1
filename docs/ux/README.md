# UX/UI-перероблення інтерфейсу «AS-IS аналіз → BPMN»

Статус: **пропозиція дизайну, не реалізація.** Чинний продукт (`public/`, `src/`) не змінювався.

| Файл | Що це |
|---|---|
| `../../design/prototype/index.html` | Ізольований інтерактивний прототип. Відкривається локально, без сервера продукту. |
| `ux-spec.md` | Коротка UX/UI-специфікація: структура, компоненти, стилі, поведінка. |
| `problem-change-table.md` | Таблиця «проблема → зміна → яку зайву роботу прибирає → залежність від сервера», збережені захисні правила, пріоритети. |
| `verification.md` | Що саме перевірено, якими командами, що працює в прототипі, що симульовано, що потребує інтеграції. |
| `shots/` | Знімки станів на 1440×900, 1280×720 і вузькому екрані. |

## Як відкрити прототип

```
cd design/prototype && python3 -m http.server 8777
```
Далі відкрити `http://127.0.0.1:8777/index.html`. Файли можна відкрити і просто з диска (`file://`): зовнішніх запитів немає.

Чорна смуга вгорі — **керування прототипом**, а не частина продукту: вибір процесу (два синтетичні кейси)
і вибір стану маршруту (десять станів). У продукті цієї смуги не буде.
