# Знімки станів прототипу

Усі знімки зроблено з `design/prototype/` (Playwright + Chromium, без мережі, синтетичні дані).

## 1440×900 — кейс CX (топологія схеми = реальна версія 29)

| Файл | Стан маршруту | Що видно |
|---|---|---|
| `01` | 1 · Новий процес | Бізнес-контекст порожній, «Ще не з’ясовано» — допустимий стан; наступна дія веде до джерел |
| `02` | 1 · Джерела | Пакет джерел, один вибір походження на весь пакет, одне оновлення, платний етап позначено до запуску |
| `03` | 2 · Після першого аналізу | Короткий контекст → наступна дія → увага → межі → головні зміни |
| `04` | 2 · Кроки | Таблиця кроків і бічна панель із деталями й точною цитатою джерела |
| `05` | 2 · Проблеми | Тип проблеми й критичність — окремі позначки; що сталося → чому → що блокується → хто діє → дія |
| `06` | 3 · Нове інтерв’ю | Додано / змінено («було → стало» з наслідком) / суперечить / потребує рішення |
| `07` | 4 · Пакет змін | Прев’ю наслідків: що додається, що вилучається, переходи, втрачені прив’язки, що лишиться відкритим, поле відповіді |
| `08` | 4 · Після застосування | Узгоджений стан, відповідь на критичне питання збережено разом із пакетом |
| `09` | 5 · Рішення чинне | «Рішення чинне — пов’язаний зміст не змінився» + перелік виконаних перевірок |
| `10` | 6 · Рішення на перегляд | «Потрібно переглянути — змінилися …» + попереднє пояснення в полі, без повторного введення |
| `11` | 7 · Погодження | Одне змістовне підтвердження: версія, межі, суттєві зміни, залишкові некритичні питання |
| `12` | 8 · Тривала операція | Час від початку, відомий етап, час останнього стану, без вигаданого відсотка |
| `13` | 8 · Втрата оновлень | Окремий стан: «не доводить, що операція зупинилась»; ручне оновлення, без дубля запуску |
| `14` | 9 · Технічна помилка | Причина людською мовою → що збережено → що не прийнято → витрати → наступна безпечна дія |
| `15` | 10 · Схема | Реальна топологія v29: 12 дій, 19 елементів, 21 перехід; відомі вади пайплайна названо окремо |
| `16` | 10 · Перехід до кроку | Центрування елемента, масштаб 140 %, вибраний елемент підсвічено |
| `17` | 10 · Історична схема | Версія схеми, чинна версія опису, причина неактуальності |
