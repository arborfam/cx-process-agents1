# Як оновити локальне демо на Windows зі збереженням даних

Ваші кейси лежать у папці **`data`** всередині папки проєкту. ZIP-архів гілки **не містить** `data` і `node_modules`, тому оновлення коду їх не зачіпає. Нижче — безпечний порядок із резервною копією.

> Перевірено на Linux (усі тести, оновлення на копії даних попереднього випуску). **На Windows я цих кроків не запускала.**

## Кроки (командний рядок cmd)
1. **Зупиніть застосунок:** у вікні cmd натисніть `Ctrl+C` (на запитання «Terminate batch job» — `Y`).
2. **Резервна копія даних.** У Провіднику відкрийте папку проєкту, скопіюйте папку `data` (`Ctrl+C`, `Ctrl+V`) і назвіть копію `data-backup`. Копіюйте цілу папку, а не один файл.
3. **Завантажте нову версію:** відкрийте `https://github.com/arborfam/cx-process-agents1/tree/claude/peaceful-allen-f4yf0n` → **Code → Download ZIP** (саме ця гілка, не `main`).
4. **Розпакуйте поверх папки проєкту.** Найпростіше: Extract All у ту саму папку, де лежить ваш проєкт (наприклад, `C:\cx-demo`), і на запитання про заміну файлів обрати **«Замінити файли в папці призначення»**. Папки `data`, `data-backup` і `node_modules` у ZIP немає, тож вони лишаються.
   - *Якщо не впевнені:* розпакуйте в **нову** папку, скопіюйте в неї свою папку `data`, а далі — крок 5 з `npm install`.
5. Відкрийте cmd у папці проєкту (клацнути в рядок адреси Провідника, ввести `cmd`, Enter) і виконайте:
   ```
   chcp 65001
   npm install
   npm run demo
   ```
   `npm install` після оновлення швидкий (набір залежностей той самий); якщо ви розпакували в нову папку — він потрібен обов’язково.
6. Відкрийте посилання з консоли. Код доступу в `data\access-code.txt` лишився, тож вхід працює як раніше.

## Що ви маєте побачити
- Усі ваші кейси на місці. Демо-кейс не дублюється (`npm run demo` не перезаписує наявний).
- Новий порядок картки: **Суть → Опис процесу AS-IS (перша вкладка «Бізнес-контекст і межі») → Критичні прогалини й наступна дія → Головні зміни → Перевірки готовності** (згорнуті).
- У старих кейсах — пункт «**Початковий крок**» у прогалинах. Оберіть крок і натисніть «Зафіксувати початковий крок» (для демо — S1). Для погодженого кейсу це створює нову версію і скасовує погодження старої (воно лишається в історії): версію треба погодити знову.

## Якщо щось пішло не так
Зупиніть застосунок, видаліть папку `data`, перейменуйте `data-backup` на `data` і запустіть попередню версію коду (або цю ще раз). Дані в резервній копії не змінювались.
