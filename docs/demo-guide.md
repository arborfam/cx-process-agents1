# Як особисто відкрити демо зрізу 1 і пройти сценарій

Стан: **ДЕМОРЕЖИМ — не AI.** Перевіряється програмна логіка (збереження, версії, блокування, погодження), а не якість аналізу. Усі матеріали синтетичні (вигадані). Жодних викликів моделі немає.

## Обмеження поточного середовища (прямо)

Застосунок працює в тимчасовому cloud-контейнері Claude Code на адресі `localhost`, яка **недоступна з вашого браузера**. Постійного розміщення немає (рішення D6 не прийняте, нічого не опубліковано). Тому є два способи:

1. **Подивитися без встановлення** — знімки екранів справжнього проходження сценарію в браузері: папка `docs/demo/` (12 файлів, нумеровані за порядком). Їх можна відкрити просто в інтерфейсі GitHub/Claude.
2. **Запустити на вашому комп’ютері** (потрібен Node.js) — інструкція нижче. Це єдиний спосіб клацати самій. **Я перевіряла запуск лише в Linux-контейнері;** на вашому Windows/Mac він не пробувався.

## Запуск на вашому комп’ютері (≈10 хвилин)

1. Встановіть **Node.js 22** (LTS) з nodejs.org. Перевірте у терміналі: `node --version` (має бути v22.13 або новіше).
2. Отримайте код: на сторінці репозиторію в GitHub оберіть гілку `claude/peaceful-allen-f4yf0n` → **Code → Download ZIP** → розпакуйте. (Або `git clone` і `git checkout claude/peaceful-allen-f4yf0n`.)
3. Відкрийте термінал (Windows: PowerShell) **у розпакованій папці** і виконайте:
   ```
   npm install
   npm run demo
   ```
4. У терміналі з’явиться блок із рядком **«Відкрийте: http://localhost:3000/login?code=…»**. Скопіюйте це посилання в браузер. Код у посиланні — це ваш «вхід людини»; лише з ним можна погоджувати.
5. Угорі сторінки завжди видно жовту смугу **«ДЕМОРЕЖИМ — не AI»**.

Зупинити: `Ctrl+C` у терміналі. Дані зберігаються у файлі `data/cx.sqlite`. Почати з чистого аркуша: зупиніть застосунок і видаліть папку `data`.

Якщо порт 3000 зайнятий: `PORT=3001 npm run demo` (Mac/Linux) або `$env:PORT=3001; npm run demo` (PowerShell).

## Сценарій перевірки (≈10 хвилин)

Демо-кейс «ДЕМО: Зміна умов обслуговування» створюється автоматично. Питання **Q1 задано сценарієм демо**, а не виявлено AI — це написано на картці.

| № | Дія | Що має статися |
|---|---|---|
| 1 | Відкрийте кейс зі списку | Статус «Дослідження»; блок «Блокери погодження: 2» (один — критичне питання Q1) |
| 2 | Натисніть «Закрити критичні питання» | Відкриється вкладка «Питання» |
| 3 | Вкладка «Твердження й докази» → «Показати фрагмент у джерелі» | Підсвічується точна цитата в тексті інтерв’ю. Твердження про «єдиний канал» позначено як **пропозицію, а не факт AS-IS** |
| 4 | Вкладка «Питання» → у полі Q1 напишіть: `Керівник відділу повідомляє клієнта листом про відхилення винятку, після чого заявку закривають.` → «Закрити питання уточненням» | Створюється **нова версія** (3) і нове джерело «Уточнення до Q1»; Q1 закрито; критичних питань немає, лишається один блокер «Робочу версію 3 ще не прийнято аналітиком». Але кроки в описі ще не враховують відповідь — це робимо далі |
| 5 | «Редагувати» → у полі «Кроки» змініть рядок S5 на `S5 \| Керівник відділу \| Вирішує, погодити чи відхилити виняток \| Рішення щодо винятку \| S4 (погоджено); S6 (відхилено)` і додайте новий рядок `S6 \| Керівник відділу \| Повідомляє клієнта листом про відхилення \| Клієнта поінформовано \| END` → «Зберегти як нову версію» | Версія 4; у «Головних змінах» — «Додано крок S6» |
| 6 | «Прийняти робочу версію» | Позначка «Прийнято аналітиком (це ще не погодження)» |
| 7 | «Передати на погодження» | Статус «На погодженні» |
| 8 | «Погодити цю версію AS-IS» → позначте 4 пункти → «Погодити версію 4» | Статус «AS-IS погоджено», у шапці — дата погодження |
| 9 | «Дозволити створення BPMN» | Повідомлення, що **сервер підтвердив дозвіл**. Самої схеми ще немає (зріз 3) |
| 10 | Вкладка «Джерела» → додайте будь-яке коротке джерело | Кейс **повертається до «Дослідження»**, погодження стає скасованим; кнопка BPMN знову недоступна. Вкладка «Історія» показує старе погодження зі скасуванням |
| 11 | Зупиніть застосунок (`Ctrl+C`), запустіть знову `npm run demo` | Кейс, версії й історія на місці; демо-кейс не задвоївся |

## Що спробувати «зламати»

- Додайте файл `.docx` як обов’язкове джерело: буде «⚠ НЕ прочитано», у блокерах — червоний пункт, погодження неможливе.
- Змініть критичне питання на некритичне: система вимагає пояснення.
- Спробуйте погодити, коли є блокер: кнопка веде до блокера, сервер відхилить і прямий запит.

## Що в цьому демо ще НЕ працює

- Кнопка «Оновити аналіз (AI)» вимкнена: справжнього агента ще немає (зріз 2, потрібен ключ моделі).
- BPMN не будується; є лише перевірка дозволу на сервері (зріз 3).
- Підсумкового документа немає (зріз 4).
- Підтримані файли: лише `.txt` і `.md`.
